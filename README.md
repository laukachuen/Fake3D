# Fake3D

## How to Clone & Build

Place `GameFramework` and `Fake3D` in the **same folder** side-by-side:

```text
ParentFolder/
 ├── GameFramework/
 └── Fake3D/
```

git clone [https://github.com/laukachuen/GameFramework.git](https://github.com/laukachuen/GameFramework.git)

git clone [https://github.com/laukachuen/Fake3D.git](https://github.com/laukachuen/Fake3D.git)
